# Navin Shripathi — Marketing Portfolio

Static portfolio website for Navin Shripathi, positioned as an end-to-end Brand & Growth Marketing Strategist/Manager.

## Run locally

Open `index.html` in a modern browser, or serve the folder with any static web server.

## Current build

- Bright, responsive multi-page portfolio
- Six featured homepage clients
- Full Client Multiverse with 21 case studies
- Five-scene horizontal client stories
- Five-card Creative Work shuffle decks
- Muted looping reels with opt-in sound

The website is deployed through Vercel from the `main` branch.
